# 课表解析与空闲时间段计算工具 (schedule-calculator)

## 功能介绍
本项目是一个基于 Python 的课表解析小工具，包含以下功能：
1. **需求1**：从 CSV 文件（`schedule.csv`）读入课表，并输出【本次课表】的文本视图。
2. **需求2**：给定每天的可用时间范围（08:00 - 22:00），计算并输出每天的空闲时间段。支持连续时间段合并（小于 30 分钟的碎片时间不显示）。
3. **需求3**：支持输入多人的课表（如 `schedule_B.csv`），计算所有人共同的空闲时间段，结果按空闲时长从高到低排序。

## 如何使用
1. 确保电脑已安装 Python 环境。
2. 准备 CSV 文件，格式为：`课程名,星期几,开始时间,结束时间`。
3. 在终端中运行：
   ```bash
   python main.py
